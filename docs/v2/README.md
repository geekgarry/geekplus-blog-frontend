## 怎么用这些稿子

1. **标题**：可直接用各文一级标题，或改成更「标题党」一点的对外标题。  
2. **配图**：示意 PNG 可直接用；发文前建议再补 2～3 张线上真实截图。  
3. **代码**：文中是「核心摘录」，完整实现以本仓 `src/` 为准；鉴权与缓存以 API 仓为准。  
4. **系列互链**：每篇文末有「上下篇」导航，发布时改成你博客的真实 URL。

祝发文顺利。
