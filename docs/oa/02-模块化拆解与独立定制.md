# 02 · OA 物料边界说明

> OA 与博客同仓集成。  
> **不用 OA 时有两种做法**（逻辑去掉 / 物理删除）：见 [03-去掉方式手册](./03-裁剪与去除操作手册.md)。  
> 后端契约：[19-OA-Flowable](../../GeekPlus-Blog-API/docs/19-OA-Flowable.md)；设计器布局：[01](./01-BPMN设计器布局与画布高度.md)。

---

## 1. 前端归属

| 路径 | 说明 |
|------|------|
| `src/views/admin/oa/**` | 工作台 / 设计器 / 流程 / 待办 / 申请 / 组件 |
| `src/api/oa/**` | `designer.js`、`files.js`、`org.js` |
| `src/styles/oa-theme.css` | 主题与 BPMN 浅色画布（`admin.scss` 引入） |
| `src/utils/oaBpmnBrand.js` | 设计器品牌显隐 |
| `src/router/local-routes.js` | OA 隐藏路由：`designer/:id`、`process/detail/:instanceId` |
| `package.json` → `bpmn-js` | 仅 OA 强依赖 |
| `mock/data/menus.js` | OA 菜单段（约 4000–4005；API SQL 约为 540+） |

宿主共用：`@/utils/request`、Vuex 用户信息、管理端 Layout / `loadView`。

---

## 2. 后端归属（`GeekPlus-Blog-API`）

| 路径 | 说明 |
|------|------|
| `com.geekplus.oa.**` | Controller / Service / Entity / Mapper / Listener / Config |
| `resources/mybatis/oa/**` | MyBatis XML |
| `resources/db/migration_oa_*.sql` | 业务表 + 菜单 + 试用种子 |
| `pom`：`flowable-spring-boot-starter-process` | 仅 BPMN，勿用全量 starter |
| `OaFileAccessFilter` | `/oa/files/**` 签名或 JWT |

---

## 3. 契约摘要

- HTTP：`/oa/designer`、`/oa/files`、`/oa/org`  
- 权限前缀：`oa:*`；菜单挂载 path=`oa`  
- 组织数据：优先 `api/oa/org.js`，避免页面直调 `@/api/system/*`

---

## 4. 以后若要拆独立包（可选）

将归属目录迁到 npm / Maven 模块，由宿主注入 `http`、用户信息与菜单。  
当前不需要 OA 时：优先读 [03](./03-裁剪与去除操作手册.md)——**逻辑去掉**（保留代码）或 **物理删除**。
