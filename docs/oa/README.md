## 列表操作列约定

按钮过多时拆两列（与 plus-admin-antd 对齐）：

| 列 | 是否 fixed | 内容 |
|----|------------|------|
| **更多** | 否，随表横向滚动 | 次要操作 |
| **操作** | `fixed="right"`，约 2～3 个 | 主操作 |

已应用：待办（更多=回退/加签/转办；操作=同意/拒绝/详情）、流程管理（更多=源码/发布|停用；操作=编辑/删除）、我的申请不拆列。
