## 原则（全阶段适用）

1. **ZIP 与菜单发布解耦**：生成代码不强制服务端摸开发者磁盘；发布菜单只写 DB。  
2. **幂等**：菜单以 `component` 为业务键；低代码后期以 `appId + pageId` 为键。  
3. **权限与菜单契约**：与 `permission.js`、`@RequiresPermissions` 前缀一致。  
4. **后端文档**：API 契约写在 `GeekPlus-Blog-API/docs/`；本目录侧重产品与前端架构。
