# 当前能力与发布菜单（P0）

本文描述 **已落地 / 刚落地** 的代码生成与菜单发布流程，不含「服务端读盘校验」。

---

## 1. 用户流程

```
导入表 → 配置 gen_table → 预览 / 下载 ZIP
         ↓
    解压合并到前后端工程（人工）
         ↓
    本地启动验证 CRUD
         ↓
    管理端「发布菜单」→ 写 sys_menu + 可选角色授权
         ↓
    重新登录 / 刷新权限 → 侧栏出现新菜单
```

**ZIP 与发布菜单是两个独立步骤**，后端不负责检查 Vue 是否已合并。

---

## 2. 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/generator/download/{tableName}?uiType=` | 下载 ZIP；`uiType=element\|antd`（默认 element） |
| GET | `/generator/downloadByGenTable/{tableIds}?uiType=` | 下载 ZIP（原有 + uiType） |
| GET | `/generator/previewCodeByGenTable/{tableId}?uiType=` | 预览代码 |
| GET | `/generator/table/publishMenuPreview/{tableId}` | 预览将写入的 component、权限前缀、是否已发布 |
| POST | `/generator/table/publishMenus` | 幂等发布菜单 |

- **Element** → `vue.ftl`；**Ant Design Vue** → `vue-antd.ftl`（含动态条件查询表单）
- 详情：后端 [16-代码生成双前端模板-uiType.md](../../GeekPlus-Blog-API/docs/16-代码生成双前端模板-uiType.md)

本仓库管理端「代码生成」页可切换前端模板（默认 Element）；Plus Admin 默认 Ant Design Vue。


### 2.1 发布请求体

```json
{
  "tableId": 12,
  "parentMenuId": 3,
  "menuName": "图书管理",
  "path": "book",
  "icon": "table",
  "roleIds": [1]
}
```

### 2.2 发布结果

```json
{
  "alreadyPublished": false,
  "mainMenuId": 2001,
  "component": "function/book/index.vue",
  "permissionPrefix": "function:book",
  "moduleName": "function",
  "businessName": "book",
  "menuIds": [2001, 2002, 2003, 2004, 2005, 2006],
  "message": "发布成功，主菜单 ID=2001"
}
```

### 2.3 幂等规则

- 查询 `sys_menu`  where `component = '{moduleName}/{businessName}/index.vue'`  
- 已存在 → `alreadyPublished=true`，**不插入**，仍可补 `roleIds` 授权  

### 2.4 事务与菜单结构

单事务内：

1. 插入主菜单 `menuType=M`，`perms={prefix}:list`  
2. 批量插入按钮 `B`：`info / add / update / delete / export`（与 `controller.ftl` 一致）  

### 2.5 审计

- `@Log(title="代码生成发布菜单", businessType=PUBLISH)` → `sys_oper_log`  
- 业务日志：`operator, tableId, moduleName, businessName, component`

## 3. 前端入口

| 文件 | 说明 |
|------|------|
| `src/views/admin/tool/generator/index.vue` | 操作列「生成代码」「发布菜单」 |
| `src/views/admin/tool/generator/GenPublishDialog.vue` | 发布对话框 |
| `src/api/tool/generatorTable.js` | `publishMenuPreview`、`publishGenMenus` |

### 3.1 component 约定

动态路由（`permission.js`）：

```javascript
require([`@/views/admin/${item.component}`], resolve)
```

因此 ZIP 内 Vue 应落在：

```
src/views/admin/{moduleName}/{businessName}/index.vue
```

菜单 `component` 字段：

```
{moduleName}/{businessName}/index.vue
```

示例：代码生成器自身菜单为 `tool/generator/index.vue`。

## 4. ZIP 内容结构（合并参考）

与 `CodeGenerateByTemplate.getTemplateCodeStream` 一致：

| 产物 | ZIP 内路径 | 合并到 |
|------|------------|--------|
| Vue 页 | `/views/{module}/{business}/index.vue` | `src/views/admin/...` |
| API JS | `/api/{module}/{business}.js` | `src/api/...` |
| Controller 等 | Java 包路径 | API 工程 `src/main/java` |
| Mapper XML | `/mybatis/{module}/` | `resources/mybatis/` |

## 5. 常见问题

**Q：发布菜单后 404？**  
A：ZIP 未合并或 `component` 路径与文件不一致；检查 `views/admin` 下是否有对应 `index.vue`。

**Q：按钮无权限？**  
A：确认角色已授权新菜单；或发布时勾选角色；或 `sys_role_menu` 手动补数据。

**Q：重复发布会怎样？**  
A：第二次 `alreadyPublished=true`，不会 duplicate 菜单行。

**Q：为何不用 sys/menu/add 多次调用？**  
A：聚合接口保证 **事务**、**幂等**、**统一审计**；避免前端连点插重复数据。
