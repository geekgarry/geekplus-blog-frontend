# 用户管理 · 动态条件查询

与 Plus Admin 对齐：列表筛选项改为「字段 + 运算符 + 值」。

## 前端

- 组件：`src/components/DynamicQueryForm/index.vue`（Element UI）
- 页面：`src/views/admin/system/user/index.vue`
- 请求参数：`conditionsJson`（JSON 字符串），勿传嵌套数组

## 后端

需部署含动态查询能力的 API（`GeekPlusAdmin-Security-JWT`）：

- `BaseEntity.conditionsJson`
- `DynamicQueryHelper.prepare`
- `mybatis/common/DynamicQueryMapper.xml` → `DynamicWhere`
- `SysUser` 白名单 + `SysUserMapper` include

详见后端文档：`GeekPlusAdmin-Security-JWT/docs/动态条件查询.md`
